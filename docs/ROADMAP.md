# Roadmap

## Foundation

- [x] Establish the design direction and native Breeze foundation.
- [x] Create the local repository structure and initial documentation.
- [ ] Select publishable sources, editable artwork and per-file licensing records.

## Icons

- [ ] Consolidate Eden, Waydroid, PCSX2, DuckStation and Settings artwork.
- [ ] Complete icon aliases, resolution/scale metadata and native lookup checks.
- [ ] Extend actions, places, devices, status and emblems with appropriate profiles.

## Appearance

- [ ] Implement complete light and dark Flexoki semantic color schemes.
- [ ] Review contrast and interaction states in both variants.
- [ ] Build a minimal Plasma Style with Breeze fallback.
- [ ] Align panels, popups, notifications, tooltips and interaction states.

## Interaction

- [ ] Integrate reviewed dock code and its native module.
- [ ] Verify independent sizing, hover magnification and live configuration preview.
- [ ] Integrate focused KWin behavior only where needed.

## Packaging

- [ ] Assemble the Global Theme from tested components.
- [ ] Package light and dark appearance selections while sharing common resources.
- [ ] Implement the simple installer, variant selection and scoped uninstall workflow.
- [ ] Measure resource use against Breeze and record results.
- [ ] Test a supported-version matrix and recovery procedures.
- [ ] Resolve licensing and credits, then publish the first usable release.
