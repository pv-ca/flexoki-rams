# Official development references

- [KDE Plasma themes and plugins](https://develop.kde.org/docs/plasma/): component overview.
- [Creating a Plasma Style](https://develop.kde.org/docs/plasma/theme/quickstart/): structure and starting point.
- [Understanding Plasma Styles](https://develop.kde.org/docs/plasma/theme/theme-details/): metadata and Breeze fallback.
- [Theme elements reference](https://develop.kde.org/docs/plasma/theme/theme-elements/): SVG integration contracts.
- [Porting themes to Plasma 6](https://develop.kde.org/docs/plasma/theme/theme-porting-to-plasma6/): migration reference; compare examples with the actual target version.
- [Testing widgets](https://develop.kde.org/docs/plasma/widget/testing/): widget development tools.
- [Widget configuration](https://develop.kde.org/docs/plasma/widget/configuration/): configuration model and controls.
- [Icon Theme Specification](https://specifications.freedesktop.org/icon-theme/latest/): naming, directories, inheritance and scaling.
- [Qt Quick performance guidance](https://doc.qt.io/qt-6.11/qtquick-performance.html): measurement and optimization.
- [Qt QML profiling](https://doc.qt.io/qt-6.11/qtquick-profiling.html): profiling infrastructure.

Documentation URLs and maintenance branches can change. Record immutable upstream revisions when importing resources and verify their target API. Research references do not establish that a tool is installed or a feature has been tested.
