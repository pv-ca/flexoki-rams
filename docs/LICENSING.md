# Licensing status

A repository-wide license has not been selected yet. Do not treat this scaffold as a statement that all future assets share one license.

Before the first release, record the origin, copyright notices and license of each reused component. KDE/Breeze code, third-party artwork, application logos and project-created assets may require different treatment.

Preserve required notices and provide component-specific license files and credits. Confirm the scope of any final repository license before adding it. No third-party source or application artwork has been imported into this initial scaffold.
